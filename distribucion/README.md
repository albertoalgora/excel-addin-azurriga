# 📦 Add-in Azurriga para Excel - Paquete de Distribución

Este paquete contiene todo lo necesario para instalar el Add-in Azurriga en Excel.

## 📋 Contenido del Paquete

- **`instalar-addin-produccion.bat`** - Instalador automático para Windows
- **`manifest-production.xml`** - Archivo de configuración del add-in
- **`INSTRUCCIONES-INSTALACION.md`** - Guía completa de instalación
- **`iconos/`** - Iconos del add-in

## 🚀 Instalación Rápida

### Windows:

1. **Descarga o descomprime** esta carpeta completa
2. **Ejecuta** `instalar-addin-produccion.bat`
3. Sigue las instrucciones en pantalla
4. **Cierra y reabre Excel**
5. Busca el add-in en: **Insertar → Complementos de Office**

### Mac / Linux / Instalación Manual:

Consulta el archivo `INSTRUCCIONES-INSTALACION.md` para métodos alternativos.

## ⚙️ Requisitos

- Microsoft Excel 2016 o superior
- Conexión a Internet
- Windows, Mac o Excel Online

## 🌐 El Add-in Funciona en la Nube

- No requiere instalación de servidores locales
- No necesitas Node.js ni npm
- Funciona desde GitHub Pages (HTTPS seguro)
- Actualizaciones automáticas
